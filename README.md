## Gitのイメージ

| Gitの要素                  | 現実世界に置き換え |
| -------------------------- | ------------------ |
| Gitサーバー                | 大きなマンション   |
| リポジトリ                 | 部屋               |
| ブランチ                   | 作業机             |
| ソースコードやドキュメント | 箱詰めされた商品   |
| プルリクエスト             | 検品作業           |

## visiblityの違い

| 項目       | Public                 | Private               |
| ---------- | ---------------------- | --------------------- |
| コード閲覧 | 全世界                 | 招待ユーザーのみ      |
| clone      | 誰でも                 | メンバーのみ          |
| fork       | 誰でも                 | メンバーのみ          |
| GitHub検索 | 表示される             | 表示されない          |
| 主用途     | OSS / 公開プロジェクト | 社内開発 / 機密コード |
